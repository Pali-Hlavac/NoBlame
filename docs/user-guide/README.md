# NoBlame user guide

NoBlame is a fast Git client for Windows, Linux and macOS, built for very large repositories.

This guide describes version 0.1.0 (milestone M1). This first version contains the app window,
the command palette and the command line. It does not read repositories yet: repository tabs and
task windows are labelled placeholders until the commit graph arrives in the next milestone.
