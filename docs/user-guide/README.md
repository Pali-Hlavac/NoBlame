# NoBlame user guide

NoBlame is a fast Git client for Windows, Linux and macOS, built for very large repositories.

This guide describes version 0.1.0 while milestone M2 is in progress. You can open and create
repositories and browse their history in the commit graph. Commit details, committing and the
other Git operations come in later versions; task windows are labelled placeholders.
